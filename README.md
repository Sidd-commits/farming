# FarmAssist - Empowering Farmers

A modern, responsive web landing page for FarmAssist, a platform dedicated to empowering farmers with technology and smart solutions.

## Features
- Responsive navigation bar with hamburger menu for mobile
- Hero section with overlay and call-to-action
- Services section with attractive icons
- About section with image and description
- Contact section with form and contact info
- Footer with social links and newsletter subscription
- Clean, modern design using Google Fonts

## Demo
Open `index.html` in your browser to view the site locally.

## How to Use
1. **Clone or download this repository.**
2. Make sure the following files are in the root directory:
   - `index.html`
   - `styles.css`
   - `script.js`
   - `background.jpg` (or use your own background image)
3. Open `index.html` in your browser.

## Customization
- Replace `background.jpg` with your own image for a personalized hero section.
- Update service icons or add more services as needed.
- Edit contact info and social links in the footer.

## Deployment
You can deploy this site on GitHub Pages:
1. Push your code to a GitHub repository.
2. Go to your repository settings > Pages.
3. Set the source branch to `main` (or `master`) and the root folder.
4. Save and your site will be live at `https://<your-username>.github.io/<repo-name>/`.
